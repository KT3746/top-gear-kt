# Relâmpago

Jogo de corrida no navegador. Não precisa instalar nada.

**Jogue aqui:** [https://kt3746.github.io/top-gear-kt/](https://kt3746.github.io/top-gear-kt/)

## Como jogar

1. Abra o link acima.
2. Clique em **Jogar**.
3. Escolha o carro e o modo: **Campeonato** (cinco pistas) ou **Corrida rápida**.
4. Na oficina, gaste o dinheiro das corridas em motor, pneus e nitro.

### Controles

- **Setas** ou **W A S D** — acelerar, frear e dirigir
- **Shift** ou **Espaço** — nitro
- **Esc** — pausar
- **M** — ligar ou desligar o som
- **F** — tela cheia

Fique no asfalto. Sem combustível o carro perde força. Latas na pista enchem o tanque.
