# Relâmpago

Jogo de corrida no navegador. Não precisa instalar nada.

**Comece aqui:** [https://kt3746.github.io/top-gear-kt/](https://kt3746.github.io/top-gear-kt/)

São duas versões. Escolha a sua:

- **Computador:** [https://kt3746.github.io/top-gear-kt/pc/](https://kt3746.github.io/top-gear-kt/pc/) — só teclado, sem botões na pista
- **Celular:** [https://kt3746.github.io/top-gear-kt/celular/](https://kt3746.github.io/top-gear-kt/celular/) — botões grandes na tela

## Computador

1. Abra o link do computador.
2. Clique em **Jogar**.
3. Escolha o carro e o modo: **Campeonato** ou **Corrida rápida**.

- **Setas** ou **W A S D** — acelerar, frear e dirigir
- **Shift** ou **Espaço** — nitro
- **Esc** — pausar
- **M** — som · **F** — tela cheia

## Celular

1. Abra o link do celular.
2. Vire o aparelho de lado.
3. Toque em **Jogar**.
4. Na corrida, use os botões: virar, acelerar, frear, nitro e pausa.

Fique no asfalto. Sem combustível o carro perde força. Latas na pista enchem o tanque.
